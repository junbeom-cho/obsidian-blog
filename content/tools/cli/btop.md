>[!summary]
>Terminal에서 하드웨어의 CPU, Ram 사용량 등의 정보를 모니터링할 수 있는 CLI 툴 btop의 설치 및 사용법을 정리했습니다.


## Overview
CPU/RAM 사용량, 실행 프로그램, 네트워크 등의 정보를 **게임화면**처럼 모니터링할 수 있는 CLI 툴  

## Requirements
- [[homebrew]]

## Setup
### Installation
#### macOS / Linux
```bash
brew install btop
```

## Usage
```bash
btop
```
