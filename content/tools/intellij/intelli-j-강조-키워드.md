## 기본 제공 키워드
### TODO
"앞으로 해야 할 일"을 기록할 때 사용

### FIXME
"작동은 하지만 문제가 있어 수정이 시급한 부분" 또는 "망가진 코드"를 강조할 때 사용

## Custom 키워드 정의하기

### 설정 메뉴 진입
#### Windows/Linux
`File > Settings`

#### macOS
`IntelliJ IDEA > Settings` Shortcut : `Cmd + ,`

### 경로 이동
`Editor > TODO`

### 패턴 추가
1. patterns 섹션에서 + 버튼을 클릭
2. 정규표현식을 입력한다 ex) `\bNOTE\b.*
	- `\b`는 단어의 경계를 의미하여 정확히 그 단어만 찾는다.
3. Icon 지정
4. 대소문자 구분 필요하면 체크
5. Color Scheme , Font 설정 가능

## TODO 탭 활용
### 메뉴 경로
`View > Tool Windows > TODO`

### 기능
- 프로젝트 전체의 `TODO`, `FIXME` 및 등록한 커스텀 키워드를 리스트 형태로 보여줍니다.
- 클릭 시 해당 코드 라인으로 즉시 이동합니다.
- 필터(Filter) 기능을 통해 `FIXME`만 보거나, `REVIEW`만 보도록 설정할 수 있습니다.


## 추천 커스텀 키워드
| 키워드      | 의미     | 추천 사용 상황                               |
| -------- | ------ | -------------------------------------- |
| NOTE     | 참고 사항  | 코드가 왜 이렇게 작성되었는지 배경 설명이 필요할 때          |
| OPTIMIZE | 최적화 필요 | 기능은 정상이나 성능 개선이(속도, 메모리 등) 필요할 때       |
| HACK     | 임시방편   | 좋지 않은 방법인 걸 알지만, 당장 문제를 해결하기 위해 작성한 코드 |
| REVIEW   | 검토 요망  | 로직이 복잡하거나 확신이 서지 않아 동료의 코드 리뷰가 필요할 때   |
| XXX      | 경고/위험  | 큰 문제는 아니지만 주의가 필요하거나, 삭제 예정인 코드 등      |
| BUG      | 버그     | 알려진 버그가 존재하는 위치를 표시할 때                 |
